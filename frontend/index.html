Our AI-SIEM system transforms high-volume network flows into 10-minute sliding window event sets grouped by communicating host-pairs. Each set is mapped to 8 basepoint cosine similarities and classified using a regularized Soft-Voting Neural Ensemble (FCNN + CNN + LSTM) complemented by an unsupervised Isolation Forest for zero-day threat detection.

Project Overview & Academic Specification
College Capstone Project

AI-Based SIEM Cyber Threat Detection System using Artificial Neural Networks based on Event Profiles

Modern Security Information and Event Management (SIEM) systems are overwhelmed by massive network flow volume, resulting in extreme alert fatigue when traditional rule-based or per-packet inspection systems operate at scale. This project implements an end-to-end, privacy-preserving, high-throughput AI SIEM detection pipeline that operates on Event Profiles rather than inspecting raw payloads.

Methodological Principle Implementation Strategy Integrity Verification
Multi-Day Domain Shift Splitting Strict 4-way temporal partition: Mon-Thu benign train (1,997k), Wed-Thu validation (625k), Fri unseen test (569k), Tue control test (42k). PASS Unseen attack families evaluated strictly on separate days.
Threshold Non-Leakage Derived event quantiles, TF-IDF IDF weights, and basepoints fitted exclusively on training set. PASS Zero future-information leakage into validation or test splits.
Identity Protection IP addresses and port numbers strictly excluded from neural network input vectors. PASS Prevents model from memorizing specific host IPs.
Cost-Sensitive Thresholds Ensemble decision boundary calibrated on validation data (τ = 0.6561) to guarantee FPR < 3.0% under severe class imbalance. PASS 2.71% FPR on Friday unseen test (1,196 attacks in 569,099 sets).
Dual Defense Verification Supervised ensemble provides high confidence on known attacks (100% recall on Tuesday control); Isolation Forest catches out-of-distribution zero-days. PASS Defense-in-depth across both in-distribution and domain-shifted traffic.
