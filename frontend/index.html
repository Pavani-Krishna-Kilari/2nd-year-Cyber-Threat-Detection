ℹ️ About Our Project

AI SIEM Cyber Threat Detection System is designed to analyse network traffic and identify suspicious activity.

The system classifies network events into:

🟢 Normal — Safe network activity
🔴 Threat — Suspicious or malicious activity

The frontend allows users to upload datasets, analyse network records and view detection results.
